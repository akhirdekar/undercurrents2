THE IRON GRID — START HERE

This package includes the latest bright cyan/orange website, the editable code,
data preparation scripts, source data, your original slides and the earlier PDF drafts.

TO UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open Iron_Grid_Project, then dist.
3. In GitHub, open your repository > Add file > Upload files.
4. Drag EVERYTHING INSIDE dist into the upload area, keeping data and vendor folders intact.
5. Commit directly to main.
6. Settings > Pages: Deploy from a branch, main, /(root), Save.
7. Wait for the Pages deployment to finish, then click Visit site.

Upload the contents of dist, rather than the outer project folder or this ZIP.
index.html should be directly in the repository root.

TO EDIT THE WEBSITE
Open Iron_Grid_Project in VS Code or another text editor.
The site files are in dist. Read README.md for local viewing and data preparation.

DOCUMENTS
